- Watch state initialization records the high-water baseline: when the state file has no `lastEndedAt`, `check()` creates `<stateDir>/memory-watch.json` with `lastEndedAt` set to the newest real case's `endedAt` (or the current time when no real case carries one) plus `initializedAt`, prints `baseline recorded`, and returns without analyzing.
- It applies on the first `check()` for a state dir, and again whenever the state file is missing, unreadable/empty or has no `lastEndedAt`, including each `--watch` poll in that condition; as long as `lastEndedAt` exists, later runs take the analysis path instead.
- Failure mode: starting from an old or empty baseline — an empty or reset state silently adopts the newest existing case (or now) as the mark and analyzes nothing, and a stale state inherited from an earlier cases file leaves backfilled or equal-timestamp cases permanently unanalyzed, because `newRealCases` keeps only cases ending strictly after the mark.
