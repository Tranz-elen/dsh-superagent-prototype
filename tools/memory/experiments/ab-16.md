- Assignment is deterministic per ticket: `assignedPromptRevision` hashes the ticket id with FNV-1a (`hash`) and returns `experiment.revisions[hash(ticketId) % 2]`, so the same ticket always lands on the same revision.
- It applies at ticket `prepare` only when the trigger pins no `promptRevision`, `promptExperiment.enabled` is true, and `revisions` holds exactly two non-negative integers; otherwise it returns `undefined` and no revision is pinned.
- A non-deterministic assignment (for example `Math.random` or process- or time-dependent state) can flip the same ticket between revisions across retries or hosts, so the ON/OFF cohort and its comparison cannot be reproduced.
- Reviewer check: `pnpm vitest run tests/prompt-experiment.spec.ts` requires repeated calls to return the same revision for each ticket id, both revisions to appear across ids, and disabled or malformed experiments to return `undefined`.
- Source: `src/app/prompt-experiment.ts` — `assignedPromptRevision` and `hash`; called from `prepare` in `src/executor/dsh.ts`.
