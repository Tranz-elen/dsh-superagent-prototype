- `blockedReports` counts, per ON/OFF group, the number of cases that have at least one worker Report whose state is `blocked` or `failed`; a case counts once no matter how many such Reports it has, and a case with no `reports` adds nothing.
- It applies inside `summarize` for every group built by `summarizePromptRevisions`: only cases with a numeric `promptRevision`, excluding titles containing `A/B` and (unless `--include-local`) `source: 'local'` cases, and honoring `--since` on `endedAt`; the count appears in both the Markdown table and the `--json` output.
- Failure mode: treating blocked as a normal failure — the filter accepts `blocked` or `failed` alike, so a worker that stopped for a person (blocked) is counted with one that failed; reading the count as a failure rate or a prompt regression misattributes a human handoff as a defect.
