- `cases.jsonl` is a JSONL file next to the state database with one line per ended Ticket.
- It is written when `ticket.ended` fires, plus catch-up on startup; `pnpm memory:export` is the offline catch-up.
- Failure mode: worker transcripts are multi-frame zstd, so decompressing only the first frame truncates the trace digest.
- Reviewer check: `jq -c . ~/.dsh/state/superagent/cases.jsonl` parses every line, and its `id` values are unique.
- Source: `tools/memory/README.md`, Data section (transcript-frame note under Commands).
