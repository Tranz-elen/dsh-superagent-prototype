- Gate requires at least 20 cases (`--min-cases`, default 20), one `intent|outcome` cluster with `n >= 3`, and at least 2 distinct outcomes.
- Opens only when all three checks pass: it writes `dist/clusters.json`, `dist/prompt.md` and `dist/status.md` headed `# Distillation gate: open` and exits 0; a failed check writes `# Distillation gate: closed` and exits 1.
- Failure mode: distilling too early lets one vivid ticket become a rule that is a guess with a version number, reaching a prompt section without repeated, outcome-backed evidence.
- Reviewer check: run `pnpm memory:distill` and require `# Distillation gate: open` in `dist/status.md` (cases >= 20, a cluster `n >= 3`, outcomes >= 2); every rule must cite 3+ ids from `dist/clusters.json`.
