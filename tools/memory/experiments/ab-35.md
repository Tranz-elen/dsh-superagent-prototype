- `--since <ISO>` selects pinned-`promptRevision` cases whose `endedAt` is at or after the timestamp: the filter is `(!since || (c.endedAt && Date.parse(c.endedAt) >= since))`, so it bounds when a ticket ended, not when it started.
- It applies only when `--since` is passed, inside `summarizePromptRevisions` after the pinned-revision, A/B-title and local-source filters, so it narrows both the ON and OFF groups and `totalPinned`; without the flag every pinned case is compared.
- Failure mode: comparing the wrong date window — a cutoff before the experiment began admits pre-experiment tickets and a too-late one drops early ON cases, and because the boundary is `endedAt`, a ticket started before the cutoff but ended after it still counts, so the arms can span different eras and a time-driven gap is misread as a prompt effect.
