- The high-water mark stores `lastEndedAt`, the latest `endedAt` among real cases (no `A/B` title and no `source: local`), in `<stateDir>/memory-watch.json`; after an analysis the file also records `analyzedAt` and `analyzed`, and later runs compare each real case's `endedAt` against the mark.
- It applies on every `check()` run of the one-shot watch (also each 5s poll under `--watch`): the first run records `lastEndedAt` as the newest real case's `endedAt` (or the current time when no case has one), and a later run analyzes only real cases whose `endedAt` is strictly greater, then advances the mark to the newest real `endedAt`.
- Failure mode: advancing the mark on the wrong case, such as computing `latestEndedAt` over all cases instead of `realCases`, lets a local-source or A/B fixture with a later `endedAt` push `lastEndedAt` past real tickets that ended earlier, and because `newRealCases` keeps only `endedAt > lastEndedAt`, those skipped real cases are never analyzed again.
- Reviewer check: read `<stateDir>/memory-watch.json` and confirm `lastEndedAt` is not later than the newest real `endedAt` in `<stateDir>/cases.jsonl` (no real case ended after it); rerunning `node tools/memory/watch-real-tickets.mjs` right after that should print `no new real cases since <lastEndedAt>` and leave the state file unchanged.
