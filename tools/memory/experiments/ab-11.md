- The real-ticket watch (`check`) is a one-shot script that reads `cases.jsonl`, keeps real cases via `realCases` (dropping `A/B` titles and `source: local`), selects cases ending strictly after a stored high-water mark via `newRealCases`, and runs `analyze-cases.mjs` to write `memory-watch/report.md` and `failure-candidates.json`.
- It runs only when an operator or a recurring reminder invokes `node tools/memory/watch-real-tickets.mjs`; the first run just records the current latest `endedAt` (or now) as the baseline, and `--watch` re-runs `check` every 5 seconds via `watchFile`.
- High-water-mark failure: the mark only moves forward and re-baselines to the latest case when `memory-watch.json` is missing, so a case that arrives later with an `endedAt` at or before the mark (backfill, equal timestamp, lost state) is silently never analyzed.
- Reviewer check: `pnpm vitest run tests/memory-watch.spec.ts` asserts that A/B and local cases are excluded and that only cases strictly after the mark are returned.
- Source: `tools/memory/watch-real-tickets.mjs` — `latestEndedAt`/`newRealCases` (high-water selection), `realCases` (filtering), and `check`/`main` (baseline, analysis, watch loop).
